# CSE3461_Project1
Group project 1 for CSE 3461. This is a messaging app using TCP with features involving broadcast messaging, direct messaging, and a third feature decided by the group. The third feature was chosen to be a terminal using UDP and several of the techniques used by TCP to implement a two-way chat

To run feature 1: 
in feature1/client.py, change the value of SERVER_IP to the IP of the device acting as the server
server: python3 feature1/server.py
client: python3 feature1/client.py

To run feature 2:
in feature2/client.py, change the value of SERVER_IP to the IP of the device acting as the server
server: python3 feature2/server.py
client: python3 feature2/client.py

Instructions for running feature 3 are founde in feature3/README.md
